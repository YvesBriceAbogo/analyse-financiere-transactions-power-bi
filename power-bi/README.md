# Fichier Power BI Desktop

| Fichier | Description |
|---|---|
| `analyse-financiere-transactions.pbix` | Rapport complet : requêtes, modèle, mesures et pages |

## Avant ouverture

Le rapport utilise deux paramètres de chemins locaux, `PathFinance` et `PathCustomers`. Après téléchargement :

1. Ouvrez le fichier dans Power BI Desktop.
2. Cliquez sur **Accueil**, puis **Transformer les données**, puis **Modifier les paramètres**.
3. Renseignez les chemins complets des fichiers du dossier `data/`.
4. Cliquez sur **OK**, puis **Appliquer les modifications**.
